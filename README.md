# Fitxatge Manserva v.1

App de fitxatge d'hores creada amb React + Vite.

## Desplegar a Netlify

1. Puja este projecte a un repositori de GitHub (crea'n un de nou i puja tots estos arxius).
2. Entra a https://app.netlify.com i inicia sessió (pots fer-ho amb el compte de GitHub).
3. Prem "Add new site" → "Import an existing project".
4. Tria el repositori que acabes de pujar.
5. Netlify detectarà automàticament:
   - Build command: `npm run build`
   - Publish directory: `dist`
6. Prem "Deploy". En un o dos minuts tindràs l'enllaç de la teua app.

Les dades es guarden al navegador de cada persona (localStorage) — no es comparteixen entre dispositius ni usuaris.
